## 초기 데이터 적재 정책
최초 작성일: 2026-10-29
## 1. 정상 결측
### 1.1. 주말 및 휴장일
#### 조건
- 날짜 목록에서 달력상 연속된 날짜 사이에 빠진 날짜가 있다.
#### 판정
- 빠진 날짜 중 `주말`또는 `휴장일`이 True인 날짜
- 빠진 날짜가 영업일이면 오류로 봐야하지만, 영업일인지 아닌지를 판단할 수 있는 데이터나 API를 도입하지 않았기 때문에 영업일 오류를 판단하지 못함
- 따라서, 날짜 자체가 빠진 날은 정상 결측으로 판단한다.
#### 처리
- 빠진 날짜마다 기준일 이전으로 하루씩 거슬러 올라가며 해당 만기의 관측값을 찾는다.
- 관측값을 찾으면 그 값을 복제한다.
#### 결과 값
- 찾은 경우: 복제한 값
- 가장 최근 영업일이 없어 휴장일인지 판단 할 수 없는 경우: ValueError

### 1.2. 주석에 명시한 미 제공일
#### 조건
- 재무부 사이트 주석에 명시된 기간 안에 있다.
- 해당 만기의 값이 없다.
#### 판정
- 다음 세 조건이 모두 참이면 판정
  1. 날짜가 명시한 기간에 있다.
  2. 해당 만기의 값이 없다.
  3. 같은 날짜의 다른 만기 값이 1개 이상 있다.
- 3번이 거짓이면 날짜 자체가 없는 것이기 때문에 1.1로 판정
#### 처리
- 해당 만기만 None으로 처리
#### 결과 값
- None


## 2. 비정상
### 2.1. 날짜 필드 누락 또는 변환 실패
#### 조건
- 날짜 필드가 없거나 date로 변환이 불가하다.
#### 판정
- 날짜 필드 부재, date 변환 예외 발생
#### 처리
- 날짜를 알 수 없으므로 해당 레코드 제거
#### 결과 값
- 레코드 제거

### 2.2 날짜 중복
#### 조건
- 같은 날짜가 두 개 이상의 레코드로 존재한다.
#### 판정
- 날짜 기준 그룹에 레코드가 2개 이상
#### 처리
- 값이 완전히 같으면 하나만 남기고, 다르면 예외를 발생시킨다.
#### 결과 값
- 중복 제거 후 1개 레코드

### 2.3 만기 수익률 float 변환 실패
#### 조건
- 날짜는 정상이다.
- 다른 만기 값은 변환 가능하다.
#### 판정
- 특정 만기 값을 float로 변환할 수 없다.
#### 처리
- 해당 만기 값을 None으로 둔다.
- 원본 문자열을 로그로 남긴다.
#### 결과 값
- None
