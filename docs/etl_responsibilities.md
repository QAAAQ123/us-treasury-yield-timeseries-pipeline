# ETL 단계별 책임
최초 작성일 2026-10-24
## Extract — 추출
- 미국 재무부 API 요청
- 요청 인자 검증 및 HTTP 예외 처리
- 원본 XML 응답 반환

## Transform — 변환
1. XML 파싱
2. 필요한 날짜 및 만기별 금리 필드 추출
3. 컬럼명 및 자료형 정규화
4. 결측값·중복 날짜·금리 값 등 데이터 정합성 검증
5. 검증 결과에 따라 데이터 처리
6. CSV 저장에 적합한 DataFrame 생성

## Load — 적재
- CSV 파일 저장
- 기존 데이터와 신규 데이터 병합
- 중복 제거 및 최종 데이터셋 갱신
